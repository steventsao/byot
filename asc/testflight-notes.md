byot 1.0.17 — everyday OpenCode controls

- Find slash commands and choose a primary agent, model, or supported reasoning variant. Queued messages keep their chosen settings.
- Browse and read project files on your server, search with @, and attach files or selected line ranges as context.
- Undo and redo conversation turns, compact long conversations, and fork a session from its history when supported by your server.
- Rename and delete sessions, inspect session details, and navigate child sessions.
- Follow task progress when the server provides it.
- Touch and hold a response to select and copy part of its text, or use Select code inside a code block.

Please try these controls with your OpenCode 1 or OpenCode 2 server. Check queued messages, file context, history recovery, and session management in both appearances and with larger text. Available controls follow the server's capabilities. OpenCode 2 conversation undo does not roll back workspace files.
