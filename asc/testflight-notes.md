byot 1.0.15 — input, previews, and session navigation

- Write messages in one input container with attachment, model, and send/stop controls together. Attachment-only messages can be queued while a turn runs.
- Preview attached photos and documents before sending; closing a preview keeps the draft intact.
- Search sessions beside the compose button at the bottom. New sessions show server and project choices on the page, including another working directory.
- Server dropdown selections align consistently, and Edit server opens the selected saved connection.
- Errors seen in a conversation appear in its session list and are rechecked when returning. Session-status sorting includes these failures.
- The lowercase byot wordmark and app icon share Open Runde. Light/Dark appearance and large-text layouts remain supported.

Please check both OpenCode 1 and OpenCode 2 connections, large text, image/document previews, changing the server for a new session, and returning to the list after a provider error.
