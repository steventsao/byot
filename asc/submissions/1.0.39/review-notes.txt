BYOT 1.0.39 (20261102195608) is a native iPhone and iPad client for OpenCode running on the user's own computer, over OpenCode's public HTTP/SSE API. Commands execute on the configured server; BYOT renders responses and does not download or execute code on iOS. BYOT is independent and is not affiliated with OpenCode.

There is no BYOT account, tracking or in-app purchase. Usage data (PostHog) is off by default; see USAGE DATA below. Server passwords are stored in the iOS Keychain. The review server has a scratch workspace and needs no VPN, Tailscale, browser sign-in, MFA or invitation.

REVIEW SERVER
Name: App Review
URL: https://testflight.byot.app
Username: opencode
Server password: use the secure demo-account password field in App Review Information.
Working directory: /workspace

REVIEW STEPS
1. Launch BYOT and tap Add server (or the plus in the server bar). Enter the Name, URL, Username and Server password above; the password is required. Enter /workspace under Working directory.
2. Tap Test connection, then Save. Select App Review in the server bar.
3. Tap compose/New session. Select App Review and /workspace; if it is not listed, choose Other directory and enter /workspace. Tap Start session.
4. In the composer, choose the OpenCode provider's Big Pickle model. Send: Reply exactly: BYOT App Review connection verified. Watch it stream. For tools, send: List the files in this project and summarize the README without changing files. Answer any permission request with Allow once.
5. Attach a photo/document from the composer plus menu, or Files to browse project files. Send is disabled until imports finish.
6. Type a draft, leave the session, reopen it, then relaunch BYOT; the draft is restored only in that session.
7. In the session browser, search, sort or group; swipe left to Archive.

CHANGES SINCE APP STORE 1.0.35
Bug fixes only; no new features or data collection. Leaving the projects screen or session list mid-load treated the cancelled request as a failure and could leave an error and a blank workspace behind; cancellation is now recognised and the last known state kept. Session rows say "Connecting" while BYOT reaches the server, instead of "Status unavailable", now kept for a server that answered with an error. The camera, microphone, speech and local-network prompts had explanations only in Simplified Chinese and could appear in English without their reason; the English values are now explicit. The same four permission keys are declared; none added.

USAGE DATA
About 1.5 s after a launch with a saved server, a half-sheet asks "Share anonymous usage data?"; Not now sends nothing. About byot (info button) > Privacy has the switch. With it on, BYOT sends seven event kinds to PostHog (US): app opened, server connected, session started, turn requested, turn completed, error category, star card shown. Fixed values and counts only; never prompts, replies, code, file or project names, server addresses, user names, passwords or error messages. A request cancelled by leaving a screen is no longer reported as a network error, and a server connected while the question was open is counted only on opt-in. PrivacyInfo.xcprivacy and the App Privacy label are unchanged: Product Interaction, Other Diagnostic Data, Device ID (random install id) and Coarse Location, all Analytics, not linked, no tracking. Details: https://byot.app/privacy

OPTIONAL COMPANION FEATURES
Notifications and the computer queue are opt-in and not needed for the review above. Saved server menu > Notifications shows a one-time pairing code and the command for the OpenCode computer; Session actions > Message queue enables it after pairing. The relay stores APNs registration/preferences and encrypted queued prompts. Local drafts use iOS file protection and are excluded from backups.

OpenCode 1 and 2 are supported; controls follow server capabilities. OpenCode 2 undo does not roll back workspace files. There is no offline demo; use the review server.
