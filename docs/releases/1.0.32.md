# BYOT 1.0.32 — optional anonymous usage data, and a star ask

This release adds opt-in product usage events and a once-every-six-days ask for a GitHub star (later, Apple's review prompt) after a completed turn. It builds on the 1.0.31 source (`d1b3c64`, `main`). The contract is [docs/features/telemetry.md](../features/telemetry.md); the public description is the privacy policy in `web/src/information.ts`.

## What changed

| Area | Change |
| --- | --- |
| `Sources/BYOTTelemetry.swift` | Six-event schema with fail-closed validation, consent state, install id, kill switches, PostHog transport with every automatic capture off |
| `Sources/BYOTTelemetryOpenCode.swift` | Vocabulary: address kind (never the address), provider/model/agent allow-lists, error classes, turn properties |
| `Sources/BYOTTelemetryConsentView.swift` | One-time half-sheet question and the About byot → Privacy switch |
| `Sources/BYOTApp.swift` | Starts telemetry, records launches and resumes, asks once after the first server is saved |
| `Sources/OpenCodeClient.swift` | `server_connected` on the first negotiated adapter per server per launch; `session_started` |
| `Sources/OpenCodeSessionStore.swift` | `turn_requested` on send/queue/computer queue/shell; `turn_completed` when a byot-requested turn goes idle; `error_occurred` on send and turn failures |
| `Sources/OpenCodeSessionBrowserStore.swift` | `error_occurred` when a session list fails to load |
| `Sources/BYOTNudge.swift`, `Sources/BYOTNudgeCard.swift` | Value-moment gate (third completed turn, 6-day cooldown, doubled bar on Later) and the star card; About byot → Support byot links; see [docs/features/star-nudge.md](../features/star-nudge.md) |
| `Sources/PrivacyInfo.xcprivacy` | Declares Product Interaction, Other Diagnostic Data, Device ID, Coarse Location: not linked, not tracking, analytics purpose |
| `Sources/Resources/Localizable.xcstrings` | Nine new strings with Simplified Chinese |
| `project.yml` | `posthog-ios` 3.89.0; `MARKETING_VERSION` 1.0.32 |
| `web/src/landing.ts`, `web/src/information.ts` | "No analytics" claims replaced with opt-in wording; new "Optional usage data" policy section |
| `Tests/BYOTTelemetryTests.swift`, `Tests/BYOTNudgeTests.swift` | Schema, consent, gates, dedupe, vocabulary, error classes; nudge threshold, cooldown, Later, starred → review |
