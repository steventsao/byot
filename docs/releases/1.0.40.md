# BYOT 1.0.40 — Finished turns fold under a timed header

This build brings three pieces of Codex's transcript polish to BYOT. Every turn has a header that times it. A finished turn folds to its answer and the files it changed. Tool calls made back to back share one line. It goes to TestFlight only.

## Why 1.0.40

1.0.39 (`20261102195608`, archived from `56d7cba`) is waiting for App Store review. This build adds the transcript change merged in [steventsao/byot#119](https://github.com/steventsao/byot/pull/119) (`b291249`), so it takes the next number rather than putting a second source behind 1.0.39. The 1.0.39 submission is untouched.

## What changed since 1.0.39

| Area | Change |
| --- | --- |
| Transcript turns (`OpenCodeTranscriptParts.swift`, `OpenCodeSessionView.swift`) | Replies are gathered under the prompt they answer: the one their `parentID` names, else the latest prompt before them. Each turn has a header with a hairline. It says "Working for 25s" while OpenCode runs, ticking every second, then "Worked for 2m 12s", "Stopped after…" or "Failed after…", using the Live Activity's rules for how a turn ended. A running turn whose server clock is a day or more from the device's shows no timer. |
| Folding | A finished turn opens folded. It shows its last stretch of prose, the files and images it produced, its subagent cards, one combined "Changed N files" list and any error. Tool calls, reasoning, the narration between them and step footers open from the header. A turn that only answered has nothing to open. A running turn always shows everything. |
| Tool runs | Two or more tool calls in a row, across steps, become one line such as "Read 3 files · Ran 2 commands", with reasoning and step footers inside. The newest run of a working turn opens by itself. Subagent tasks break a run. |
| OpenCode 2 notice (`OpenCodeCompatibility.swift`) | The degraded-mode notice says "OpenCode 2." instead of "OpenCode 2 beta.", now that 2.x is released. From [steventsao/byot#117](https://github.com/steventsao/byot/pull/117), which also pins the released OpenCode 2 schema in tests. |
| Strings | 17 new, all with Simplified Chinese translations. One changed: the OpenCode 2 notice above. |
| `Sources/Info.plist` | Unchanged, so no permission or privacy-label change. |

[steventsao/byot#118](https://github.com/steventsao/byot/pull/118), which also landed after 1.0.39, adds a live permission acceptance test only and changes nothing in the app.

## Validation

Run on the Mac mini (Xcode 26.5) using the existing iPhone 17 simulator "byot-baseline" (iOS 26.5), from this branch.

| Run | Result |
| --- | --- |
| `BYOTTests` | **791 tests: 783 passed, 8 skipped (live-server tests), 0 failed**. That is 676 swift-testing tests in 71 suites plus 115 XCTest tests, 8 of them skipped. #119 added the `Transcript turns` suite (8 tests) and #117 the OpenCode 2 GA contract suite. |
| `OpenCodePolishUITests` (4 transcript tests) and `OpenCodeSubagentUITests` (all 4) | Passed before #119 merged. They cover the folded turn, opening it to reach the retry notice, step footer and checkpoint, the running timer under the prompt, step footers in opened turns, the long history without prompts, and subagent cards that still open their sessions. |

## Not covered

- No UI fixture has two tool calls in a row, so tool runs are covered by unit tests only.
- The full `BYOTUITests` target was not run.
- The App Privacy label is unchanged and was not re-published.
