# BYOT 1.0.37 — Reliable refresh and readable permission prompts

The October 27 audit returned 73 screenshot feedback submissions and two crash
submissions. No new report arrived after 1.0.36. The latest item,
`AJd8dKpVdvbuffcbZ2FQRa0` ("Why status unavailable?"), already received its
Connecting/pending-status fix in [1.0.36](1.0.36.md). This release follows that
feedback through the cancellation path and includes the diagnostics fixes
merged after that build. Baseline: `6eaea56` in the dedicated `steventsao/byot`
iOS repository. The older `byot-platform` checkout is not the release source.

## Changes

- Workspace refresh handles both Swift task cancellation and URLSession's
  cancellation error. Leaving the list or backgrounding byot must not clear
  the last known server compatibility or show a false connection failure.
- Cancelled tasks cannot publish late probe or project responses; a superseded
  refresh cannot replace a newer response or dismiss its loading indicator.
- The previously merged `f2308bf` change stops recording cancelled session-list
  requests as network failures. When optional usage data is enabled after a
  server was already negotiated, its pending connection event is sent after
  consent. Consent requirements and the event schema are unchanged.

Real connection failures still display their explanation. The existing timeout
and offline-cache behavior are preserved.

## Permission string packaging correction

Apple processing of the first upload (`20261027115114`) surfaced warning 90738
for the English camera and speech-recognition prompts. Inspecting that IPA
confirmed that all four English permission values were raw Info.plist key
names. The catalog had Chinese translations but no explicit English values,
so Xcode compiled the keys as English overrides despite valid base plist copy.
The first candidate briefly completed internal distribution after the stop
request; its Internal Testers access was then removed and independently
verified as zero tester groups. It is superseded by the corrected build.

All four catalog entries now explicitly carry the existing English purpose
text (camera, microphone, local network and speech recognition). A regression
test inspects the compiled language tables, rejects empty/raw-key values in
both languages, and verifies English matches the base Info.plist. The corrected
release uses build `20261027124118`; final validation is pending. The earlier
UI screenshots exercise unchanged layout code from the first candidate.
