# byot Brand

The iOS brand refresh uses a strict black-and-white palette, lowercase `byot` wordmark, and system-native rounded typography.

- `byot-chatgpt-image-2-concept.png` is the generated concept reference.
- `byot-icon-reference.svg` is the deterministic black app-icon reference.
- `byot-wordmark.svg` is the deterministic lowercase wordmark reference.

Production iOS icons are exported into `Sources/Assets.xcassets/AppIcon.appiconset/`.
